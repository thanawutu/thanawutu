How it works

saved search “Imperva V2 - Auto unblock (daily)” · 02:17

  1. ReadIP rule ของทุก policy (cache ทุก 5 นาที) + IP ที่ block จาก Splunk
  2. Last attacklog “Blocked IP” ของ Imperva ทุกชั่วโมง = IP ยังส่ง request เข้ามา
  3. Check dailyไม่โจมตีครบ 7 วัน (cloud / shared IP) / 60 วัน → unblock · ข้าม Keep
  4. Unblockผ่าน SOAR + verify · audit log · ถ้าโจมตีใหม่ → กลับมาหน้า Block
